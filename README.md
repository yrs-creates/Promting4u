# ✨ Prompting4U 🚀
Turn simple ideas into powerful AI prompts 💡

🔗 Live: https://prompting4u.vercel.app/

## 🎯 Features
- 🛠️ Prompt Studio – detailed prompts with style, lighting & camera 📷
- 📚 Topic Simplifier – hard topics in easy words with example 🌍
- ⚡ Summarizer – long text to 3 bullets in seconds 📝
- 🔥 Hook Generator – viral hooks for Reels & Shorts 🎬
- 🌸 Piku – cute live assistant on screen 💬

## ⚙️ Use
1️⃣ Type idea ✏️ → 2️⃣ Generate ⚙️ → 3️⃣ Copy 📋 to any AI 🤖

## 🚀 Deploy
Upload `index.html` 📤 → Vercel 🔺 Import → Deploy 🎉

## 🧰 Built with
HTML 🌐 • CSS 🎨 • JS ⚡ – No backend, no keys 🔑❌
